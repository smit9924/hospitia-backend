# Contributing

Thank you for contributing to Hospitia. The contributing guide for all three repositories lives in hospitia-master:

**[Read the contributing guide](https://github.com/smit9924/hospitia-master/blob/main/CONTRIBUTING.md)**

In short: branch from `main` as `<type>/<description>`, follow the [standards](https://github.com/smit9924/hospitia-master/blob/main/docs/standards/index.md), run the checks, update the docs and the changelog in `hospitia-master`, and open a pull request using the template. By taking part you agree to the [code of conduct](https://github.com/smit9924/hospitia-master/blob/main/CODE_OF_CONDUCT.md).
